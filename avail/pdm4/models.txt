Prefix テーブル
name: プレフィックス - コード生成時の接頭辞（例：AAA）
description: 説明 - プレフィックスの用途や使用条件等の説明
code_type: コード種別 - 生成されるコードの種類（組、部品、購入品）
next_number: 次の採番 - 次に割り当てる連番

Code テーブル
code: コード - 生成された完全なコード文字列
name: コード名 - 部品コードの名称
prefix: プレフィックス - このコードが使用するプレフィックス
description: 説明 - コードの詳細説明
status: ステータス - コードの現在の状態
sequential_number: 連番 - プレフィックス内での採番

CodeVersion テーブル
code: 部品コード - バージョン管理対象のコード
version: バージョン番号 - コードのバージョン（1から順に増加）
code_number: コード番号 - 生成された完全なコード番号
is_current: 現行バージョン - このバージョンが現在有効なバージョンかどうか
status: ステータス - このバージョンの承認状態
reason: 変更理由 - このバージョンでの変更内容と理由
changed_by: 変更者 - このバージョンを作成したユーザー
effective_date: 有効開始日 - このバージョンが有効となる日時

CodeChangeLog テーブル
code_version: コードバージョン - 変更が発生したコードバージョン
changed_at: 変更日時 - 変更が行われた日時
changed_by: 変更者 - 変更を行ったユーザー
change_type: 変更種別 - 実施された変更の種類
reason: 変更理由 - 変更を行った理由の詳細説明
previous_status: 変更前ステータス - ステータス変更前の状態
new_status: 変更後ステータス - ステータス変更後の状態
additional_info: 追加情報 - 変更に関する追加情報をJSON形式で保存

CodeMetadata テーブル

unit: 単位 - 部品の単位（個、m、kg等）
material: 材質 - 部品の材質情報
keywords: キーワード - 部品の検索用キーワード
category: カテゴリ - 部品の分類カテゴリ
notes: 備考 - その他の補足情報
specifications: 仕様情報 - 部品の詳細仕様をJSON形式で保存
weight: 重量(kg) - 部品の重量
dimensions: 寸法 - 部品の寸法情報

Tree テーブル

description: 説明 - ツリーの用途や特徴についての説明
status: 状態 - ツリーの現在の状態
version: バージョン - ツリーのバージョン番号
created_by: 作成者 - ツリーの作成者
last_modified_by: 最終更新者 - ツリーの最終更新者

status: 状態 - ノードの現在の状態
code: 関連コード - このノードに関連付けられた部品コード

quantity: 数量 - この構造での使用数量
effective_date: 有効開始日 - この構造が有効となる日時
expiry_date: 有効終了日 - この構造が無効となる日時
